# 設計書

現行実装（ソースコード）をリバースエンジニアリングして作成した設計書一式です。将来の仕様ではなく、実装済みの構造・振る舞いを記述しています。

1. [アーキテクチャ設計書](01_architecture.md) — 技術スタック、レイヤ構成、モジュール依存関係、設計原則
2. [基本設計書](02_basic_design.md) — 機能一覧、画面設計、データ項目定義、業務ルール概要、非機能要件
3. [詳細設計書](03_detailed_design.md) — モジュール/関数仕様、処理シーケンス、バリデーション・CSV・集計・描画の詳細ロジック
