# 事前学習課題

家計簿アプリの課題に取り組む前に、Python の基本をひとつずつ練習するための課題です。
1ファイル＝1テーマになっているので、`step01` から順番に進めてください。

## 進め方

1. VSCode で `step01_variables.py` を開く
2. 右上の ▷（Run Python File）を押して実行する
3. 画面下のターミナルに「答え合わせ」の結果が表示される
4. `"""STEPxx-x START"""` 〜 `"""STEPxx-x END"""` の間を、補足を読みながら修正する
5. もう一度実行して、全部 ○ になったら次のファイルへ進む

- 詰まったら、各ファイルの「ヒント」を読んでください。
- 「ここから下は答え合わせ用です」より下は変更しないでください。
- ライブラリのインストールは不要です（Python だけで動きます）。

ターミナルから実行する場合は、次のように入力します。

```powershell
python pre_study/step01_variables.py
```

## ステップ一覧

| ファイル | テーマ | 本課題で使う場所 |
|---|---|---|
| `step01_variables.py` | 変数・print・エラーの読み方 | 全体 |
| `step02_function.py` | 関数と return、f-string、split | 基本課題05 |
| `step03_if.py` | if / else、三項演算子 | 基本課題03・04 |
| `step04_nested_if.py` | 二重 if 文（ネスト） | 基本課題06 |
| `step05_convert_error.py` | 文字列→数値の変換、raise | 基本課題07、応用課題01 |
| `step06_list_for.py` | リスト・for 文・len・スライス | 応用課題01・02 |
| `step07_import/main.py` | 別ファイルの関数を使う、ボタンに関数を登録 | 基本課題02 |
| `step08_gui.py` | はじめての画面（tkinter） | 基本課題01・02 |

所要時間の目安：STEP01〜07 で 50〜75 分、STEP08 で 15〜20 分。

## STEP07 の実行について

`step07_import` フォルダの中の `main.py` を開いて実行してください。
`logic.py` は読むためのファイルなので、修正は不要です。

## STEP08 について

実行するとウィンドウが開きます。ファイルの先頭にある「完成イメージ」と同じ見た目になり、
ボタンが説明どおりに動けばクリアです。確認が終わったらウィンドウを閉じてください。
