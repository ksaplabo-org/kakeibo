# 事前学習 解答例

`pre_study/` の解答例です。ファイル構成は `pre_study/` と同じで、
`START` 〜 `END` の間だけが修正済みになっています。

- 受講者が正解できているかは、各ファイルを実行したときの「答え合わせ」がすべて ○ になるかで確認できます。
- 解答はこの例のとおりでなくても構いません（例：`len(row) not in [3, 4]` の代わりに `len(row) != 3 and len(row) != 4` と書いてもよい）。
- STEP01-1 は、まず修正せずに実行してエラーメッセージを読ませることが目的です。
- STEP08 は答え合わせがないため、画面の見た目とボタンの動作を一緒に確認してください。

問題ファイルと差分を比べると、修正箇所だけを確認できます。

```powershell
git diff --no-index pre_study pre_study_answers
```
