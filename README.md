# 家計簿アプリケーション

Python + Tkinterで作成したシンプルな家計簿管理アプリケーションです。日々の支出・収入をカテゴリ別に記録し、CSV形式での保存・読込や、カテゴリ別・年別・月別の統計表示を行うことができます。

データはアプリ実行中はメモリ上で管理され、CSVファイルに保存することで永続化します。

## 1. 概要

家計簿アプリケーションは、日々の支出・収入をカテゴリ別に記録・管理するためのシンプルなデスクトップアプリケーションです。収支の一覧表示、CSVファイルによるデータの保存・読込、カテゴリ別／年別／月別の統計表示（グラフ・表）を行うことができます。

Windows上で動作するTkinter製のGUIアプリケーションです。

---

## 2. 主な機能

- 支出・収入の登録（種類・日付・カテゴリ・金額・メモ）
- カテゴリ別の分類管理
- メモの記入
- 登録済み収支の編集・削除
- CSVファイルへの保存、CSVファイルからの読込
- 合計金額の表示（支出合計・収入合計・ネット残高）
- 統計表示（カテゴリ別・年別・月別の集計とグラフ表示）

## 6. 使い方

### 6.1 収支の追加

1. **種類を選択**: 「支出」または「収入」のラジオボタンを選択
2. **日付を入力**: `YYYY/MM/DD` 形式（例: 2026/01/20）
3. **カテゴリを選択**: 種類に応じたカテゴリが一覧から選べます
4. **金額を入力**: 詳細は [6.5 金額・日付の入力ルール](#65-金額日付の入力ルール) を参照
5. **メモを入力**: 任意のメモを記入（省略可）
6. **「追加」ボタンをクリック**

### 6.2 収支の編集

1. 一覧から編集したい行を**ダブルクリック**
2. フォームに内容が反映される
3. 必要な項目を修正
4. **「更新」ボタンをクリック**

### 6.3 収支の削除

1. 一覧から削除したい行を選択（複数選択可: Ctrl + クリック）
2. **「選択削除」ボタンをクリック**
3. 確認ダイアログで「はい」を選択

### 6.4 フォームのクリア

**「クリア」ボタン**をクリックすると、入力フォームがリセットされます。

### 6.5 金額・日付の入力ルール

#### 金額

- **1以上の整数**（0、負数、小数は入力エラーになります）
- 上限はありません
- 先頭に `¥` を付けられます
- 3桁区切りのカンマを使用できます（正しい3桁区切りの場合のみ有効）
- 全角数字も入力できます（自動的に半角数字として扱われます）

入力例（いずれも有効）:

```text
1000
1,000
¥1,000
１０００
```

無効な入力例:

```text
0          → 1以上ではない
-1000      → 負数
1000.5     → 小数
1,00       → 3桁区切りが不正
```

#### 日付

- `YYYY/MM/DD` 形式（例: `2026/01/20`）
- `YYYY/M/D` のように月・日のゼロ埋めを省略した形式も有効（例: `2026/1/20`）
- 区切り文字は `/` のみで、`-` 区切り（`2026-01-20`など）は無効です
- 実在する日付である必要があります（例: `2026/02/30` は無効）

### 6.6 カテゴリ

カテゴリは種類（支出／収入）に応じて用意された一覧から選択します（自由入力はできません）。

#### 支出カテゴリ

- 食費
- 日用品
- 交通
- 交際費
- 娯楽
- 住居
- 光熱費
- 医療
- 教育
- 貯金
- その他

#### 収入カテゴリ

- 給与
- ボーナス
- 副業
- 投資
- その他収入

## 7. CSV入出力

### 7.1 CSV形式

基本の形式は以下の5列です。

```csv
日付,種類,カテゴリ,金額,メモ
2026/01/20,支出,食費,1500,スーパーで買い物
2026/01/20,収入,給与,250000,1月分給与
```

- ヘッダー行（`日付,種類,カテゴリ,金額,メモ`）は自動的に認識されます。ヘッダー行がないファイルも読み込めます
- インポート時は **4列（メモ列なし）または5列** の行を受け付けます。6列以上ある行は不正な行として扱われます
- 空行は無視されます
- 文字コード
  - **読込**: UTF-8（BOMなし・BOM付きのどちらにも対応）
  - **書出**: UTF-8（BOMなし）

### 7.2 エクスポート

「保存」ボタンでCSVファイルに書き出します。

- ヘッダー行を必ず出力します
- **日付順**（昇順）に出力されます。同じ日付のデータが複数ある場合は、登録・取込した順序が維持されます

### 7.3 インポート

「一括取込」ボタンでCSVファイルを読み込みます。読込時の重要な仕様は以下のとおりです。

- 読み込んだデータは **既存データに追記** されます。既存データが置き換わることはありません
- 各行は個別に検証され、**正しい行だけが取り込まれる部分成功方式** です。日付・金額・種類・カテゴリ・列数などが仕様に合わない行はスキップされます
- 取込後、成功した件数とスキップされた件数がメッセージで表示されます
- **同じ内容の重複チェックは行われません**。同じCSVファイルを2回読み込むと、データが2重に登録されます。再取込を行う際は注意してください
- ファイル自体が開けない・読めない場合（文字コードの問題やファイル破損など）は、取込は行われません

## 8. 統計機能

「統計」ボタンをクリックすると、統計ウィンドウが開きます。以下の3種類のタブで、支出・収入を切り替えながら集計結果を確認できます。

- **カテゴリ別**: カテゴリごとの合計・件数・割合（円グラフとテーブル）
- **年別**: 年ごとの合計・件数（棒グラフとテーブル）
- **月別**: 月ごとの合計・件数（棒グラフとテーブル）

統計機能の集計・グラフ描画には pandas と matplotlib を使用しています。

---

## 9. データ仕様

- **金額**: 日本円の整数（詳細は [6.5](#65-金額日付の入力ルール) を参照）
- **日付**: `YYYY/MM/DD`（詳細は [6.5](#65-金額日付の入力ルール) を参照）
- **種類**: 「支出」または「収入」
- **カテゴリ**: 種類ごとに定義された一覧から選択（[6.6](#66-カテゴリ) を参照）
- **メモ**: 任意の文字列（省略可）
- **合計計算**: ネット残高 = 収入合計 − 支出合計

データはアプリ実行中のみメモリ上に保持され、アプリを終了するとデータは失われます。データを残したい場合は、CSVファイルとして保存してください。

## 12. トラブルシューティング

### `.venv\Scripts\activate` を実行すると「スクリプトの実行が無効になっている」エラーが出る

**原因**: Windows PowerShellの実行ポリシーにより、既定では `Activate.ps1` などの未署名スクリプトの実行がブロックされています。

**解決方法**: 同じPowerShellウィンドウ内で、activateする前に以下を実行してください。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\activate
```

`-Scope Process` により、今開いているPowerShellウィンドウだけに一時的に適用されます（ウィンドウを閉じれば元に戻り、システム全体の設定は変更されません。管理者権限も不要です）。ウィンドウを開き直すたびに、この1行を再度実行する必要があります。

毎回入力するのが煩わしい場合は、現在のユーザーに対して恒久的に許可することもできます（管理者権限は不要ですが、設定の永続的な変更になります）。

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

### CSVファイルが文字化けする、または取込時にエラーが出る

このアプリの読込は UTF-8（BOMなし・BOM付きのどちらも）に対応しているため、Excelなどで「CSV UTF-8」として保存したファイルもそのまま読み込めます。

このアプリが書き出すCSVはBOMなしのUTF-8です。エクスポートしたファイルを他のアプリで開く際に文字化けする場合は、開く側でUTF-8として読み込むよう指定してください。

UTF-8 以外の文字コード（Shift-JIS など）で保存されたファイルを一括取込しようとすると、「ファイルの文字コードを読み取れませんでした」というエラーが表示されます。その場合はファイルを UTF-8 で保存し直してから再度お試しください。

### 日付入力でエラーが出る

**原因**: 日付の形式が正しくない

**解決方法**: `YYYY/MM/DD`（例: `2026/01/20`）または `YYYY/M/D`（例: `2026/1/20`）の形式で、実在する日付を入力してください。`YYYY-MM-DD` のようなハイフン区切りは使用できません。

### 金額に小数点が入力できない

**仕様**: 金額は整数のみを受け付けます。小数を入力するとエラーになり、登録されません。

**解決方法**: 金額は整数で入力してください（例: `1500`）。
